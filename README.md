# About
This application allows users to effortlessly record their voice using their device's microphone and convert it into text with a single click, powered by OpenAI's Whisper model.

https://github.com/user-attachments/assets/a1522a43-5746-4a44-97bf-587d8fdad595

Once the transcription is complete, the result can be instantly previewed or downloaded as a `.txt` file! 🚀
