# About
This application allows users to effortlessly record their voice using their device's microphone and convert it into text with a single click, powered by OpenAI's Whisper model.

https://github.com/user-attachments/assets/e71dd9bf-8b65-444e-aebb-506bc7f25220

Once the transcription is complete, the result can be instantly previewed or downloaded as a `.txt`, `.docx` or `.pdf` file! 🚀
